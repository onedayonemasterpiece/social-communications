# Social Communications

Автоматизированные проверки и сценарии работы с публичными веб-интерфейсами социальных платформ.

## MAX Web canary

Workflow `.github/workflows/max-web-canary.yml` использует Playwright и репозиторный secret `max_session`, открывает официальную веб-версию MAX, находит чат «Избранное», идемпотентно отправляет тестовое сообщение и сохраняет приватные диагностические артефакты GitHub Actions.

Секреты, необработанный HTML и значения browser storage в репозиторий не записываются.
