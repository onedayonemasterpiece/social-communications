# Единый реестр адресатов социальных платформ

## Зачем он нужен

Пользователь ставит задачу естественным языком и может назвать канал неточно: «в анонсы», «в афишу», «в Ух ты» или с небольшой опечаткой. Семантический слой ассистента преобразует формулировку в стабильный logical key. Исполнитель каждой платформы затем самостоятельно проверяет точный фактический адресат и права на действие.

LLM не выбирает первый похожий результат, не подменяет платформу и не нажимает commit-кнопку. При неоднозначности выполнение останавливается до создания публикации.

Канонический публичный источник:

```text
config/social-destinations.public.json
```

Закрытые личные чаты и внутренние aliases не должны попадать в публичный файл. Для MAX они могут добавляться через `MAX_DESTINATIONS_JSON`; аналогичные приватные overlays для других платформ должны вводиться только при фактической необходимости.

### Telegram «Ух ты, Калининград!»

Публичные каналы `@wheretogo39` и `@youwillsee39` имеют другие фактические названия: «Полюбить 39 | Экскурсии» и «Экскурсии39». Поэтому исполнитель не подставляет их вместо «Ух ты, Калининград!».

Пока username не подтверждён авторизованной сессией, реестр требует `exact_dialog_title`: просмотреть доступные каналы, найти ровно один broadcast-канал с точным заголовком и проверить `post_messages` до любого изменения. При нуле или нескольких совпадениях действие блокируется.

## Границы ответственности

Семантический слой:

- учитывает контекст диалога;
- выбирает logical key и платформу;
- задаёт готовый текст, медиа, время и тип операции;
- задаёт уточняющий вопрос, если смысловая неоднозначность остаётся.

Детерминированный исполнитель:

- разрешает только запись из реестра;
- проверяет фактический username, group id или заголовок;
- проверяет административные права;
- проверяет стабильный idempotency marker;
- выполняет commit только после всех preflight-гейтов;
- возвращает минимальный receipt без credentials и приватного DOM.

## Проверенные источники

На 7 августа 2026 года:

- Telegram usernames и названия `@kldevents`, `@kenigevents`, `@lovekenig` подтверждены публичными Telegram metadata;
- VK community ids, screen names, titles и `admin_level=3` подтверждены авторизованным `groups.getById` через `VK_ACCESS_TOKEN5`;
- два MAX-канала подтверждены авторизованным Playwright smoke без открытия композера;
- отдельный MAX smoke после перехода на общий реестр завершён успешно.

## Правило изменения

Новый адресат добавляется только после проверки платформенного идентификатора. Нельзя выводить соответствие из похожего названия, ссылки в старом тексте или соседней платформы. Для каждой платформы хранится собственный точный идентификатор и способ верификации.
